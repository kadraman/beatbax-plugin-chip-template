# Contributing

This repository is a **starter template** for BeatBax chip plugins. You are
encouraged to fork it, rename the example chip, and publish your own plugin.

For how to build chip plugins, read:

- [Creating BeatBax Chip Plugins](https://github.com/kadraman/beatbax/blob/main/docs/contributing/creating-plugins.md)
- [Plugin system specification](https://github.com/kadraman/beatbax/blob/main/docs/features/complete/plugin-system.md)

For contributing to BeatBax itself (including its code of conduct and
development workflow), see the main repository's
[CONTRIBUTING.md](https://github.com/kadraman/beatbax/blob/main/CONTRIBUTING.md).

Before submitting a change here:

1. Run `npm run build` — the TypeScript project must compile cleanly.
2. Run `npm test` — all tests must pass.
3. Keep the example chip (`blip`) buildable and testable out of the box.
